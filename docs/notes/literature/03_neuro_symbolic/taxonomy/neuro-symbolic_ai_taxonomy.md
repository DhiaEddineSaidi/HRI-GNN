# Bader and Hitzler’s Classification

| Axis          | Dimension                           | Description                                                                                                                                                                                 |
| ------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Interrelation | Integrated vs Hybrid                | - **Hybrid systems**: use multiple techniques running in parallel <br>- **Integrated systems**: embed symbolic knowledge within a neural architecture.                                      |
|               | Neuronal vs Connectionist           | - **Neuronal models**: focus on cognitive plausibility<br>- **Connectionist models**: emphasize computational reasoning capabilities.                                                       |
|               | Local vs Distributed Representation | Describes whether symbolic knowledge is encoded locally or distributed across neural networks. (==a predicate by neuron is local==)                                                         |
|               | Standard vs Non-standard            | - **Standard systems**: use conventional techniques like backpropagation<br>- **Non-standard architectures**: may better represent structured knowledge but often reduce learning capacity. |
| Language      | Symbolic vs Logical                 | - **Symbolic**: uses structured data (e.g., graphs)<br>- **Logical**: systems rely on formal logic expressions.                                                                             |
|               | Propositional vs First-order        | Differentiates between simple propositional logic and more expressive [[logic_types\|first-order logic]]                                                                                    |
| Usage         | Extraction vs Representation        | Determines whether information is extracted from activations or explicitly symbolically represented.                                                                                        |
|               | Learning vs Reasoning               | Separates systems focusing on learning patterns from those emphasizing logical inference.                                                                                                   |
